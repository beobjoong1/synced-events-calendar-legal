My calendar is connected but shows no events

Synced Events Calendar · Questions: beobjoong@gmail.com

The dashboard lists your calendar as connected, yet the widget on your site is empty or misses events you can see in Google, Outlook, Teamup or ChMeetings.

Start with the Status column

In your Wix dashboard open Apps → Synced Events Calendar and read the Status column. It has five states:

  • N events with "Synced …": the last sync worked. If the widget still looks empty, see refresh timing.
  • No events found: the feed answered without an error but produced nothing for the window. The line underneath says which of the causes below applies.
  • Partial: the line reads Too large to keep whole: kept N of M events, sometimes with descriptions dropped.
  • Error: the sync failed; the line shows the reason, for example The calendar address was not found (HTTP 404). A red banner, A calendar is not syncing, repeats it: visitors keep seeing the last good copy until the next successful sync.
  • Not shown: the calendar is on but beyond your plan's limit (one on Free, ten on Pro). Switch another off, remove it, or upgrade.
Temporary problems such as The calendar address did not answer within 8 seconds. often clear on the next refresh; the app waits for a second failure in a row before it alerts you. Sync now retries immediately.

Cause 1: the feed exports only Public events

The hint under No events found usually reads: The feed answered but contained no events. Most tools export only public events (ChMeetings, Teamup, Google): make the events public, then "Sync now".

On a live site, a ChMeetings feed synced without any error and still held zero entries: none of its events had been marked Public. Teamup feeds and Google public calendars likewise carry only what the provider treats as public.

  1. In the source tool, set each event you want on the site to Public.
  2. Click Sync now in the app dashboard; the status should change to N events.

Cause 2: a Google secret address pasted under "public calendar"

The Google Calendar — public calendar option expects a Calendar ID that looks like an email address. A secret iCal link pasted there is refused with This is a secret iCal address. Choose "Google Calendar — private (secret address)" above and paste it there.

  1. In Where is the calendar? choose Google Calendar — private (secret address).
  2. Paste the Secret address in iCal format from Google Calendar → Settings → Integrate calendar.
  3. Click Check, then Connect. The address is stored encrypted and never shown to visitors.

Cause 3: the events are outside the window

Each sync covers a fixed window: from the first day of last month to the end of the same month next year. Events outside it are not fetched, and the widget navigates only inside it. When every event lies outside, the hint reads: The feed holds N entries, but none fall in the next 13 months (past events are kept for one month).

Add or move an event into the window and click Sync now.

Cause 4: the Google calendar is not public

A calendar connected by ID is read through its public address. If Google answers "not found" or returns something that is not a calendar, the status shows This Google calendar is not public. Make it public in Google Calendar settings, or use its secret iCal address (choose "Google Calendar — private").

  1. Google Calendar on the web → gear icon → Settings → pick the calendar.
  2. In Access permissions for events tick Make available to public.
  3. Click Sync now. To keep the calendar private instead, remove it and reconnect it with the secret address.

Cause 5: the feed is too large

Two limits apply. A feed over 5 MB is not synced at all: This calendar file is larger than 5 MB. A smaller feed with too many events is kept in part and shows Partial: each calendar is capped at 1,500 events, upcoming events are kept in preference to past ones, and if the stored copy is still over budget, descriptions are shortened, then dropped, then the latest-dated events are cut.

To show everything, publish a smaller calendar, such as a Teamup sub-calendar feed or a calendar that holds only upcoming events.

Cause 6: the widget is showing an older copy

Visitors see a cached copy of each feed. It refreshes every hour on Free and every 5 minutes on Pro while visitors use the site, or immediately when you click Sync now at the top of the dashboard. Events you have just added appear after the next refresh.

The Next events card in the dashboard shows what the widget shows right now. Also check that the widget sits on a published page and the calendar's On switch is on.
